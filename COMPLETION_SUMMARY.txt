🚀 QUICK START:

1. Run setup script:
   Windows: setup.bat
   Linux/Mac: bash setup.sh

2. Edit .env with database credentials

3. Create MySQL database:
   mysql -u root -p -e "CREATE DATABASE finance_app;"

4. Start application:
   python backend/app.py

5. Access at:
   http://localhost:5000
